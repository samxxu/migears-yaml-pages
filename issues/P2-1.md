# P2-1 — Duplicate mapping keys in a YAML document are silently merged by …

## Finding / 问题

- EN: Duplicate mapping keys in a YAML document are silently merged by libyaml before PHP sees the document — the second value wins and the first is lost with no warning. This is a known limitation documented in the README, but it is still a robustness gap: a typo in a key name silently drops configuration.
- 中文: YAML 文档中的重复映射键会被 libyaml 静默合并，PHP 看到文档之前第一个值就已丢失、第二个值胜出，且无告警。这是 README 中已记录的已知限制，但它仍然是一个健壮性缺口：键名拼写错误会静默丢弃配置。
- Where / 位置: `src/Compiler.php:68-86`
- Verification / 验证: static / 仅静态推断

  A decision to make repeated keys fatal would be a behaviour change and is not taken here.
